About touchpath

An open-source multi-touch attribution engine, and a place to run your own marketing data through six models at once without buying anything or signing up for anything.

The problem

Why another attribution tool.

Most attribution stops at last touch. Last touch is cheap, explainable and systematically wrong: it hands every conversion to the final click, which flatters the bottom of the funnel and starves whatever created the demand in the first place.

The models that answer the question people actually have — what happens to conversions if we turn this channel off — are the counterfactual ones: Markov-chain removal effects and Shapley values. They are well documented in the literature and rare in open source, usually sitting behind a platform that wants your data, your budget and an annual contract before it will tell you anything.

touchpath implements both, alongside the four common heuristics, so they can be run on identical paths and compared honestly.

What you can do here

All of it free, and none of it stored.

  • Run your own event data through six attribution models at once, and see where they disagree. The disagreement is the useful part: a channel every model treats the same way is a safe budget decision, and a channel with a fifteen-point spread is a decision resting on a modelling assumption nobody chose deliberately.
  • Try it first on sample data with a known answer key. Real attribution data has no ground truth, so you can never tell which model was closer. The sample datasets are simulated from explicit channel influence weights, so the right answer is recorded and every model is scored against it.
  • Check whether any of it was incremental. Attribution only ever divides credit for conversions that already happened. The holdout calculator takes a treatment and control group and tells you the lift, the confidence interval and whether it is significant — and how much of your attributed credit was real.
  • See what your feed is actually delivering. Malformed rows are counted and reported by cause, never dropped silently.

Your data

The short version: it is not kept.

Uploaded files are parsed in memory, analysed, and discarded when the request finishes. Nothing is written to disk, nothing is logged, there is no account, no cookie and no database. Reload the page and it is gone.

If you would rather not upload anything at all, that is the better option anyway — pip install touchpath and run the whole thing locally, or docker build from the repository. The hosted dashboard exists so you can see what it does before deciding whether it is worth installing.

Bring your own data

What the format needs to be.

JSON, JSONL, CSV or TSV. Each row is one event. Touches need user_id, timestamp, event_type and channel; conversions need user_id, timestamp, an event_type of purchase or conversion, and revenue.

Timestamps are forgiving — eleven common formats, plus epoch seconds and milliseconds. If your vendor uses different field names, the Python API takes a FieldMap with dotted paths for nested payloads, so you do not have to reshape the file first.

If you want real-world data rather than simulated data, Criteo publish a large public attribution dataset, and most ad platforms will export a raw event log you can feed in directly.

Why it is free

Because the interesting part of attribution is not the code — it is being able to check the answer. A measurement tool you cannot inspect is just an opinion with a dashboard. Everything here is MIT licensed, the models are implemented in readable Python, and the validation suite checks each one against hand-computed values: a symmetric channel pair must receive identical Shapley credit, a null player must receive none, a single-channel chain must have a removal effect of exactly 1.0, and every model must conserve revenue to the cent.

If you find a case where it is wrong, the repository takes issues.
